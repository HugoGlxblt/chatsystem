# ChatSystem

## Description du projet

première phase du projet 4-IR Chatsystem 
Cettte phase implémente la découverte de contacts

## Prérequis

Java JDK et Maven

## Compilation et Exécution

### Compilation
A la racine du projet,
```bash
mvn clean compile
````

### Exécution

```bash
mvn exec:java
```
